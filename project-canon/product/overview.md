# Product Overview

Status: baseline / to be confirmed

Source: current repo inspection.

`importing.ph` is a Philippines-focused shipment quotation marketplace.

The currently visible product loop is:

1. importers create shipment requests
2. forwarders browse eligible requests and submit quotes
3. importers review quote counts and private quotes
4. importer and forwarder messaging is available after quote creation
5. admins review marketplace activity and can suspend forwarder companies

The codebase currently includes:

- public marketing and guide pages
- authenticated importer surfaces
- authenticated app shell/profile/notifications surfaces
- public forwarder profile pages
- onboarding and role resolution flows
- admin marketplace safety screens

Not yet claimed here:

- production readiness
- full operational coverage beyond the marketplace loop
- complete realtime/runtime proof
