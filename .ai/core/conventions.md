# Conventions

## Commands

Update these commands to match the repository:

- Install: `<package-manager> install`
- Dev: `<package-manager> dev`
- Build: `<package-manager> build`
- Type-check: `<package-manager> typecheck`
- Lint: `<package-manager> lint`
- Test: `<package-manager> test`
- Full preflight: `<package-manager> preflight`

## Coding Conventions

- State the language, framework, formatter, linter, and test runner.
- State the preferred package manager.
- State how to target one workspace or package.
- State where new code, tests, docs, migrations, and shared contracts belong.
- Keep edits scoped to the active initiative phase.
- Do not revert unrelated dirty worktree changes.
